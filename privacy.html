rclone-book Privacy Policy

Last updated: 2026-11-08

Who uses this app

rclone-book is a personal tool. Only its owner uses it, with the owner's own Google account. It is not offered to the public.

What data it accesses

With the owner's permission, it accesses the owner's Google Drive files and Google Sheets (scopes: Google Drive and Google Sheets).

How the data is used

The data is used only to upload, list, download and update the owner's own files, from the owner's own computer, using rclone. Nothing is sent to any server other than Google's.

Storage and sharing

The OAuth token is stored only on the owner's computer. No data is collected, sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from Google Account > Third-party apps & services.

Contact

Questions can be sent through GitHub Issues.
